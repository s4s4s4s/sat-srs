# sat-srs — карта

React + TypeScript + Vite, PWA. Интервальные повторения для SAT. Карточки лежат не в приложении, а в Obsidian-vault и тянутся через GitHub API. Живёт на `s4s4s4s.github.io/sat-srs`, деплой — GitHub Actions (`.github/workflows/deploy.yml`).

## Форматы повторения

Задача показа — пара «формат × опора»: `Format` (`intro | reveal | mc | type | prep`) и `Cue` (`sentence | meaning | word`) в `types.ts` и `scheduler.ts`. Выдаёт её `pickTask`; `pickFormat` оставлен как обёртка над ним.

Зрелые карточки (`State.Review`, без авторских `choices`/`answerNum`) идут по `REVIEW_CYCLE` — четыре шага по `reps`: предложение с пропуском, значение → слово, слово → значение, ввод по буквам. **Предложение ровно на одном шаге из четырёх** — иначе словарь проверяется узнаванием фразы, а не знанием слова. `degrade` снижает шаг, если карточке нечем его обеспечить (нет `meaning_ru`, мало дистракторов, выключен `typing`). Дистракторы: `mcDistractors` — английские слова, `meaningDistractors` — русские значения по лестнице «та же часть речи и уровень → та же часть речи → любые из раздела».

Знакомство (`intro`), математика и авторские варианты в ротацию не входят.

## Тесты

`npm test` = три набора подряд: `test/session-sim.test.ts` (симуляция сессий, инварианты очереди и форматов), `test/metrics.test.ts` (цели, темп, бакеты интервалов), `test/math-pilot.test.ts` (математический путь на фикстурах `test/fixtures/math/` — разбор карточек, KaTeX, сверка числового ответа, разведение по разделам). Прогон стоит первым шагом в `deploy.yml`: красный тест блокирует выкатку. Проверки помечены кодами (C1, C3, C8…) — код в тесте и в комментарии к коду в `src/` указывают друг на друга.

Фикстуры математики лежат в репозитории намеренно: тест не должен зависеть от наличия vault на машине, иначе на сборке он падает, а локально проходит.

## Сторож дисциплины и валидатор колоды — живут не здесь

Оба переехали в отдельный репозиторий `s4s4s4s/sat-deck` вместе с колодой и журналом: сторож (`check.mjs`, пишет строку отсутствия за уже закрытый учебный день, только за него — день кончается в 04:00) и валидатор карточек. В этом репозитории (`sat-srs`) их искать не нужно — здесь только код приложения.

## Что важно знать

- **Предметы не смешивать.** Слова и математика — только отдельными разделами; interleaving допустим лишь внутри одного предмета. Нарушение этого — регресс, а не фича.
- Правки логики повторений почти всегда идут в `scheduler.ts`; правки «что видно на повторении» — в `screens/Review.tsx`.
- Дефолт настройки доезжает до установленного PWA только через `SETTINGS_VERSION` + миграцию в `store.ts`: сохранённый объект перекрывает `DEFAULT_SETTINGS` навсегда.
- Источник карточек — репозиторий `s4s4s4s/sat-deck` (ветка `main`), а не эта кодовая база: расхождения между приложением и карточками ищи в `sync.ts` / `github.ts`.
- `scripts/` — вспомогательное: `shots.mjs` (скриншоты), `make-icons.mjs` (иконки PWA).
- `package-lock.json` — 256 КБ, читать незачем.
